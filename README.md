# 剪意 ClearCut · 短剧审片意见工作台

一个面向短剧出海片方的审片意见闭环工作台原型：把平台方与客户发来的模糊审片意见，澄清为可执行的修改意图，生成修改任务，做版本对照与覆盖判断，最后导出一份可直接发给客户的《处理说明》。

## 怎么用

- 通过 HTTP 访问（构建产物使用绝对路径）：线上 https://jiaoyanming0-dotcom.github.io/clearcut-demo/ ；本地可 `python -m http.server` 后打开。
- 推荐视口 1600×900，最低 1280×720。

## 推荐体验路径（约 3 分钟）

1. 在「意见收件箱」澄清第 1 条意见（两条追问）→ 确认修改意图；
2. 依次处理第 2 条、第 3 条（第 3 条会触发"置信度低，退回人工拆解"分支）；
3. 第 4、5 条可直接确认 AI 建议——入口在收件箱顶部，可先单独确认一条，再一键批量确认剩余；
4. 在右栏「生成修改任务」直接派发；要演示超时失败，在地址后加 `?fail=1`，第一次生成会失败并可原地「重试生成」；
5. 切到「版本对照」接收 v2；逐条核对「复核结论」（已覆盖 / 部分覆盖 / 未覆盖），可人工改判并附依据与后续处置。人工改写的要求先标为待复核；
6. 「确认采用 v2」→「导出客户处理说明」查看成品文本；
7. 点「完成」后仍可查看、复制说明；改判后可按新结果重新导出。右上角图标可重置演示；右下角临时提示可点叉号单独关闭。

选「其他场景」或「说不清」时可暂存待补充，不会派发对应任务。返回「补充这条意见」，补齐明确要求与位置后，再生成任务并验收。

## 演示直达

- 在地址后加 `#/played`，一步跳到走完流程的状态（已采用 v2、已导出），适合快速看结果与录屏。
- 加 `#/compare` 跳到有修改意图与任务、但尚未采用版本的状态。
- 两个直达链接各自载入独立的默认场景，不拼接历史选择；正常打开恢复本机上次体验，首次使用或重置后从收件箱开始。
