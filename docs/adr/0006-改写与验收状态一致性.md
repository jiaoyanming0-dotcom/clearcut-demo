# ADR 0006 · 改写、待补充与验收状态一致性

日期：2026-10-31。状态：已实现。补充 ADR 0005。

GPT 浏览器复测发现：人工改写后仍派发旧要求；信息不足被计为已澄清；未生成任务时可看到完整回传；完成后没有导出入口；直达链接将历史意图与默认任务混合。

采用以下规则：

1. 已确认意图是任务的输入。人工改写同时记录修改要求和位置，任务使用改写全文。有限分支的预置证据不适用于任意新要求，改写后先标为「待复核」，由人选择结论。
2. 信息不足可暂存为「待补充」，仍计入待澄清，不派任务、不继承默认定位。补齐要求与位置后更新原意图，并重新生成任务、验收和导出。
3. 只有已生成的任务才能模拟交回 v2；回传数量随实际任务计算。未交回前显示待验收；尚无任务时展示下一步操作。
4. 后续处置由人填写。未填写时写「后续安排待确认」，不自动承诺补拍、延期集数或附件。
5. 处理说明生成完成后才可复制或完成。关闭弹窗不代表完成；完成后保留查看与复制入口。结论、依据或后续处置变化会取消旧的已生成、已复制及完成状态，采用版本保留，可重新导出。
6. `#/compare` 与 `#/played` 都从独立初始状态生成同组意图和任务，分别进入未采用与已完成状态。重置会清除直达片段，刷新后仍是初始状态。

沿用现有视觉与有限分支演示。人工改写不做自然语言解析，也不伪造新要求已经被素材满足。验收见 `../qa/v5-fixes.md`。
