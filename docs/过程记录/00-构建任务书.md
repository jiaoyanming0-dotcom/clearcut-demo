## 本次范围（Phase 1，只做这些）

在 `demo/` 目录新建 Vite + React + TS 项目（不引入任何 UI 库、字体、图标包或外部资源），完成：

1. 工程可运行：`npm install` 后 `npm run dev` 可启动；`npm run build` 通过（tsc 一并过）。
2. 设计 token：`src/styles/tokens.css` 与 `app.css`，深色专业工具风，按规格第 1 节（中性灰表面层级 + 主色青蓝 + 语义三色：覆盖绿 / 部分琥珀 / 未覆盖灰 / 错误红；正文 13px、辅助 11-12px、紧凑行高）。
3. 领域层：
   - `src/domain/types.ts`（意见、意图、任务、版本、覆盖状态、视图与步骤的完整类型）
   - `src/domain/data.ts`（规格第 4 节全部 Mock 数据逐字落盘：5 条意见、澄清问答配置、3 张任务卡、v1/v2 对照信息、客户处理说明全文）
   - `src/domain/reducer.ts`（状态机：意见状态＝待澄清 / 已澄清 / 已建任务；覆盖状态＝已覆盖 / 部分覆盖 / 未覆盖；当前视图与步骤；先实现 Phase 1 所需动作，交互动作可留 TODO）
   - `src/domain/persistence.ts`（localStorage 保存 / 恢复 / 重置，读取失败容错回退初始状态）
4. 界面骨架（三栏 + 顶栏，规格第 2 节）：
   - TopBar：产品名「剪意」、项目名「《逆光》· 出海版」、步骤指示（澄清 / 修改 / 验收）、重置 Demo 入口
   - Sidebar：剧集列表 EP11-EP15（EP13 选中、5 条新意见红点）、「术语库」灰态入口（已沉淀 12 条）
   - 中央：标签页「意见收件箱 / 版本对照」；意见收件箱完整渲染（意见卡：来源、语言、文本、时间码、状态）；版本对照与澄清面板先做空壳占位（标题 + "待 Phase 2"注释，不要做假 UI）
   - ReviewPanel：线程信息、意图清单（空态文案）、任务区占位、决策区占位
5. 全部界面文案中文、克制、无营销语气；中英内容按规格混排呈现。
